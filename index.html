Open-source quiz-show buzzers

A quiz show in a box.

Teams plug in their buzzers, a TV shows the questions and scores, and you run the game from your phone. The first team to buzz locks out the others. The BuzzerBox brings its own WiFi and needs no internet.

Get started See how it works

How it works

Set up in a few minutes

Everything a quiz needs is in the box: the buzzers' controller, the game server, the WiFi and the HDMI output for the TV.

{% include icon.html name="tv" %}

Connect the TV

Plug a TV or projector into the box's HDMI port. It shows the questions, media, scores and the podium.

{% include icon.html name="buzzer" %}

Plug in the buzzers

Up to ten wired buzzers on sturdy XLR cables, or wireless buzzers that wake up at the press of a button.

{% include icon.html name="wifi" %}

Join the box's WiFi

The box opens its own network. Join it with your phone, tablet or laptop and open buzzer.box.

{% include icon.html name="phone" %}

Host the game

As game master you start questions, play media and grade answers. Scores update on the TV right away.

Features

Made for real quiz nights

Built and refined since 2021, at parties and quiz evenings.

{% include icon.html name="offline" %}

No internet needed

The box is its own WiFi and server. It works in a cellar, a garden or a gym hall.

{% include icon.html name="buzzer" %}

Fair buzzing

A microcontroller locks the first buzzer in hardware. Wireless buzzers sync their clocks with the box.

{% include icon.html name="media" %}

Images, audio and video

Questions can show pictures, play songs or videos on the TV, and reveal clues step by step.

{% include icon.html name="edit" %}

Game editor

Write games in the browser, upload media, and move games between boxes as one file.

{% include icon.html name="trophy" %}

Scores and podium

Grade answers with one tap. Pause and resume a game, and finish with a podium on the big screen.

{% include icon.html name="update" %}

Signed updates

Install new versions from a USB stick or the browser. Each update is checked with a signature.

A look inside

The game master and the screen

One web app does both: the game master on your phone and the screen on the TV.

The projects

Open software and open hardware

The BuzzerBox is made of two projects, both open source on GitHub.

{% include icon.html name="code" %}

BuzzUI

Node.js · Angular · Ansible · CC BY-SA 4.0

The web app and the system of the box: the game server, the game master and screen app, the game editor, and the image that turns a Raspberry Pi into a BuzzerBox.

  • Game server holds the state, browsers connect over WebSockets
  • German and English, screen themes, media library
  • Reproducible Raspberry Pi OS image, signed update bundles
Repository Architecture Development setup
{% include icon.html name="chip" %}

BuzzController

ATmega328P · ESP32 · EAGLE / KiCad · GPL-3.0 / CERN-OHL-S-2.0

The hardware: the controller board with the Compute Module, the XLR board and panel, the firmware that locks the first buzzer, and the wireless buzzers.

  • 10 buzzers with LEDs, a 7-segment display and a release button
  • Serial protocol with heartbeat to the Raspberry Pi
  • Battery-powered ESP32 buzzers over WiFi
Repository Hardware versions Firmware docs
